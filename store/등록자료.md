## 권한 신고 (정책 → 앱 콘텐츠 → 민감한 권한)

**전체 화면 인텐트** (`USE_FULL_SCREEN_INTENT`)
> 핵심 기능은 약 복용 알람입니다. 부모님(어르신) 폰이 잠겨 있거나 화면이 꺼져 있어도 약 드실 시간에 알람 화면을 띄워 소리와 함께 알려 드려야 하므로 이 권한이 필요합니다. 알람시계·전화 앱처럼 사용자가 직접 설정한 시간에만 사용합니다.

**정확한 알람** (`SCHEDULE_EXACT_ALARM`)
> 약 복용 시간에 맞춰 정확히 알람을 울리기 위해 사용합니다. 알람이 몇 분 늦으면 복용 시간을 놓칠 수 있어 정확한 시간이 핵심 기능입니다.

기타 권한: 알림(`POST_NOTIFICATIONS`), 재부팅 후 알람 복구(`RECEIVE_BOOT_COMPLETED`), 카메라(사진 찍어 가족에게 보내기)

> 마이크 권한은 "말로 하기"를 앱에 넣을 때 `AndroidManifest.xml`에 다시 추가합니다. 지금 앱에는 없습니다.

## 앱 액세스 안내 (심사관용)

```
이 앱은 로그인이 없습니다. 두 개의 폰(어르신, 보호자)이 숫자 6자리로 연결되는 구조입니다.

심사 방법 (폰 한 대로 전체 확인)
1. 앱을 실행하고 첫 화면의 "먼저 체험해 보기"를 누릅니다.
2. "폰 하나로 체험"을 누르고 보호자 정보(이름 등)를 입력해 등록합니다.
3. 화면 위 주황색 막대에서 "어르신 / 보호자"를 번갈아 눌러 두 화면을 확인할 수 있습니다.
4. 막대의 "🔔 알람"을 누르면 약 알람 화면을 바로 볼 수 있습니다.

실제 사용에서는 "시작하기 → 어르신 폰"을 고르면 숫자 6자리가 나오고, 다른 폰의 "보호자 폰"에서 그 숫자를 입력하면 연결됩니다.
```

## 출시 순서 (권장)

1. GitHub Secrets에 서명 키 4개 등록 → 서명된 AAB 빌드
2. 플레이 콘솔 → 앱 만들기 → **내부 테스트** 트랙에 AAB 업로드
3. 위 신고(앱 콘텐츠, 데이터 보안, 권한)와 스토어 등록정보 작성
4. 테스터(형 + 지인)에게 링크를 보내 실제 폰으로 알람·사진·전화 확인
5. 문제 없으면 **프로덕션** 출시 신청 (심사 보통 며칠)
6. 무료 앱이라 사업자등록·통신판매업 신고는 필요 없습니다. 나중에 유료로 바꿀 때만 사업자등록 → 통신판매업 신고 → 플레이 판매자 정보 → 정기결제 상품 연결이 필요합니다. (플레이 콘솔에서 한 번 무료로 낸 앱은 유료로 바꿀 수 없어서, 유료 앱으로 팔 계획이면 새 앱으로 등록해야 합니다. 앱 안 구독 방식이면 무료 앱으로 두고 구독 상품만 추가하면 됩니다.)
