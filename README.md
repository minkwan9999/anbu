# 효도비서

어르신 폰과 보호자 폰을 잇는 시니어 AI 비서입니다.

- **어르신 폰**: 큰 버튼 3개(전화하기 / 사진 보내기 / 약 먹었어)와 "말로 하기". 설정 화면은 없습니다.
- **보호자 폰**: 약 시간, 연락처 3명(얼굴 사진·전화번호), 글자 크기를 원격으로 설정하고, 어르신이 보낸 사진과 활동 기록을 봅니다. 약을 30분 넘게 안 드시면 경고가 뜹니다.

## 써 보는 법

1. 어르신 폰에서 웹앱을 열고 **어르신 폰**을 고릅니다. QR과 6자리 숫자가 나옵니다.
2. 보호자 폰 카메라로 그 QR을 찍습니다(또는 웹앱에서 **보호자 폰** → 숫자 입력).
3. 보호자 폰에서 약과 연락처를 넣으면 어르신 폰에 바로 반영됩니다.
4. 양쪽 다 브라우저 메뉴의 **홈 화면에 추가**를 하면 앱처럼 열립니다.

**주소**: 기본 주소는 어르신 화면, 주소 끝에 `#/guardian`을 붙이면 보호자 화면입니다.
한 기기에 어르신·보호자를 둘 다 연결해도 따로 기억하므로, PC 하나로 두 화면을 번갈아 시험할 수 있습니다.

## 구조

| 위치 | 내용 |
|---|---|
| `web/` | 정적 웹앱 (빌드 없음). `app.js` 화면과 동작, `voice.js` 말 알아듣기(사투리 포함) |
| `supabase/migrations/` | DB 스키마와 함수 |
| `.github/workflows/pages.yml` | `main`에 푸시하면 `web/`을 GitHub Pages로 배포 |

- **DB**: Supabase 프로젝트 `doit-english` 안의 `hyodo` 스키마. 테이블은 API에 노출되지 않고, 앱은 기기 토큰을 확인하는 `public.hyodo_*` 함수로만 접근합니다.
- **기기 연결**: 어르신 폰을 시작하면 어르신용·보호자용 토큰이 만들어지고, 보호자 폰은 30분짜리 6자리 코드로 보호자 토큰을 받습니다. 토큰은 각 폰의 브라우저에 저장됩니다.
- **실시간**: 한쪽에서 바뀌면 Supabase Realtime 방송으로 상대 폰에 알리고, 상대 폰이 다시 불러옵니다. 1분마다 다시 불러오기도 합니다.
- **음성**: 브라우저 음성 인식(안드로이드 크롬 지원)으로 받아 적고, `voice.js`가 할 일을 정합니다. 들린 문장과 해석 결과는 `hyodo.voice_logs`에 남아 현장 테스트에서 인식률을 볼 수 있습니다.

## 아직 안 되는 것 (웹의 한계)

- 앱이 닫혀 있거나 화면이 꺼져 있으면 **약 알람이 울리지 않습니다**. 다음 단계의 안드로이드 껍데기 앱에서 해결합니다.
- 보호자 경고 알림도 **보호자 폰에서 웹앱이 열려 있을 때만** 뜹니다. 닫혀 있어도 받으려면 웹 푸시를 붙여야 합니다.
- 첫 화면(런처) 교체는 안드로이드 껍데기 앱이 필요합니다.

## 음성 인식 테스트 결과 보기

Supabase SQL 편집기에서:

```sql
select created_at at time zone 'Asia/Seoul' as 시각, heard as 들린말, intent as 해석
from hyodo.voice_logs order by id desc limit 100;
```
