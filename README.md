# 효도비서

어르신 폰과 보호자 폰을 잇는 시니어 AI 비서입니다.

- **어르신 폰**: 큰 버튼 3개(전화하기 / 사진 보내기 / 약 먹었어)와 "말로 하기". 설정 화면은 없습니다.
- **보호자 폰**: 약 시간, 연락처 3명(얼굴 사진·전화번호), 글자 크기를 원격으로 설정하고, 어르신이 보낸 사진과 활동 기록을 봅니다. 약을 30분 넘게 안 드시면 경고가 뜹니다.

## 써 보는 법

1. 어르신 폰에서 웹앱을 열고 **어르신 폰**을 고릅니다. QR과 6자리 숫자가 나옵니다.
2. 보호자 폰 카메라로 그 QR을 찍습니다(또는 웹앱에서 **보호자 폰** → 숫자 입력).
3. 보호자 폰에서 약과 연락처를 넣으면 어르신 폰에 바로 반영됩니다.
4. 양쪽 다 브라우저 메뉴의 **홈 화면에 추가**를 하면 앱처럼 열립니다.

**체험 모드**(테스트용): 체험은 **따로 된 주소** `#/demo`로 들어갑니다 (https://minkwan9999.github.io/hyodo-biseo/#/demo). 기본 주소의 시작 화면에는 실제 사용(어르신 폰 / 보호자 폰)만 보입니다.
- **폰 하나로 체험**: 체험용 어르신과 보호자가 한 폰 안에서 자동으로 연결되고, 맨 위 주황색 막대로 두 화면을 오가며 🔔 알람을 바로 울려 볼 수 있습니다.
- 체험 연결은 폰 안에 따로 저장되어, 실제로 쓰는 폰에서 체험해도 실제 연결이 지워지거나 섞이지 않습니다. **끝내기**를 누르면 실제 사용 화면으로 돌아갑니다.
- QR을 찍으면 그 어르신이 체험용인지 실제용인지 보고 자동으로 그 모드로 들어갑니다. 체험 보호자와 실제 어르신(또는 그 반대)은 서로 연결되지 않습니다.
- 체험 가구는 DB에 `demo = true`로 표시되어 실제 사용과 구분됩니다.

**보호자 한 명이 여러 어르신**(요양보호사 등): 보호자 화면 첫 화면은 맡은 어르신 목록입니다. 약을 안 드신 분이 맨 위로 올라옵니다.
**＋ 어르신 추가**를 누르거나 다른 어르신 폰의 QR을 찍으면 목록에 추가됩니다. 어르신이 한 분뿐이면 목록 없이 바로 그 어르신 화면이 열립니다.
연결할 때 넣은 보호자 이름이 활동 기록에 남습니다(예: "요양보호사 김미영 님이 저녁약을 추가했어요").

**시작 보호자**: 어르신에게 처음 연결한 보호자입니다(나중에 결제할 사람으로 봅니다). 보호자 화면 이름 아래에 표시되고,
시작 보호자만 맨 아래 **데이터 초기화**를 쓸 수 있습니다. 초기화하면 약·연락처·받은 사진·활동 기록이 화면에서 비워지고
어르신 폰과 보호자들의 연결은 그대로 남습니다. 서버에는 기록이 남아 테스트 분석에 쓸 수 있습니다.
시작 보호자가 연결을 끊으면 다음으로 먼저 연결된 보호자가 시작 보호자가 됩니다.

**주소**: 기본 주소는 어르신 화면, 주소 끝에 `#/guardian`을 붙이면 보호자 화면입니다.
한 기기에 어르신·보호자를 둘 다 연결해도 따로 기억하므로, PC 하나로 두 화면을 번갈아 시험할 수 있습니다.

## 구조

| 위치 | 내용 |
|---|---|
| `web/` | 정적 웹앱 (빌드 없음). `app.js` 화면과 동작, `voice.js` 말 알아듣기(사투리 포함) |
| `supabase/migrations/` | DB 스키마와 함수 |
| `.github/workflows/pages.yml` | `main`에 푸시하면 `web/`을 GitHub Pages로 배포 |

- **DB**: Supabase 프로젝트 `doit-english` 안의 `hyodo` 스키마. 테이블은 API에 노출되지 않고, 앱은 기기 토큰을 확인하는 `public.hyodo_*` 함수로만 접근합니다.
- **기기 연결**: 어르신 폰은 가구 토큰을, 보호자 폰은 보호자 계정 토큰을 가집니다. 보호자는 어르신 폰의 30분짜리 6자리 코드로 그 가구와 연결되고(`hyodo.guardian_links`), 한 보호자가 여러 가구와 연결될 수 있습니다. 토큰은 각 폰의 브라우저에 저장됩니다.
- **실시간**: 한쪽에서 바뀌면 Supabase Realtime 방송으로 상대 폰에 알리고, 상대 폰이 다시 불러옵니다. 1분마다 다시 불러오기도 합니다.
- **음성**: 브라우저 음성 인식(안드로이드 크롬 지원)으로 받아 적고, `voice.js`가 할 일을 정합니다. 들린 문장과 해석 결과는 `hyodo.voice_logs`에 남아 현장 테스트에서 인식률을 볼 수 있습니다.

## 보호자 알림 (웹 푸시)

보호자 화면의 **알림 켜기**를 누르면, 약을 30분 넘게 안 드셨을 때 앱이 닫혀 있어도 보호자 폰으로 알림이 갑니다.

- 서버: `pg_cron`이 5분마다 Edge Function `hyodo-push`(`supabase/functions/hyodo-push`)를 부르고, 함수가 `hyodo.claim_missed_alerts()`로 보낼 알림을 골라 발송합니다.
- 같은 약은 하루 한 번만, 약 시간 + 30분 ~ 3시간 사이에만 보냅니다. 같은 시간 약은 한 알림으로 묶습니다.
- 푸시 키(VAPID)와 예약 작업 비밀값은 Supabase Vault에만 있습니다.
- **아이폰**: 공유 → 홈 화면에 추가로 설치한 앱 안에서만 알림을 받을 수 있습니다(iOS 16.4 이상). 설치한 앱은 Safari와 저장 공간이 따로라서, 그 앱 안에서 다시 연결해야 합니다.

## 아직 안 되는 것 (웹의 한계)

- 앱이 닫혀 있거나 화면이 꺼져 있으면 **약 알람이 울리지 않습니다**. 다음 단계의 안드로이드 껍데기 앱에서 해결합니다.
- 첫 화면(런처) 교체는 안드로이드 껍데기 앱이 필요합니다.

## 음성 인식 테스트 결과 보기

Supabase SQL 편집기에서:

```sql
select v.created_at at time zone 'Asia/Seoul' as 시각, v.heard as 들린말, v.intent as 해석, h.demo as 체험
from hyodo.voice_logs v join hyodo.households h on h.id = v.household_id
order by v.id desc limit 100;
```
